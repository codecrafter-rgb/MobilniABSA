Ручни ток анотације у алату Label Studio

1. Припремити скуп без калибрационих коментара и поделити га према произвођачу:

	python prepare_dataset.py

2. Издвојити жељени сегмент CSV датотеке у JSON формат за Label Studio:

	python annotation/csv_to_json_segment.py --brand Apple --index 0

	Подразумевана величина сегмента је 50 коментара. По потреби се мења опцијом
	--segment-size, а одредиште опцијом --output.

3. У пројекат Label Studio учитати конфигурацију:

	label-studio/Labeling_Interface.xml

4. Директно увести JSON који је направила скрипта csv_to_json_segment.py. Није потребна додатна конверзија.

5. Сваки запис ручно прегледати и анотирати према упутству:

	docs/annotation_guide.md

6. По завршетку извести анотације из алата Label Studio. Сегменте једног анотатора организовати по произвођачу и, када је потребно, спојити скриптом:

	python annotation/merge_jsons.py --folder <директоријум-анотатора>

7. Када су сви главни анотаторски експорти и коначни адјудиковани калибрациони скуп спремни, формирати консолидовани скуп:

	python annotation/load_annotations.py

	Резултат је annotation/annotations.json.

8. Анализе и графиконе освежити командама:

	python analytics/absa_analytics.py <пет-калибрационих-експорта> \
	--final annotation/annotations.json --output izvestaj-analize.json

	python analytics/analyze_disagreements.py
	python analytics/refresh_report_artifacts.py
